    专业经验¶

    在过去十年中，我围绕一个目标构建了自己的职业生涯：创建安全、可扩展、有弹性且易于工程团队使用的技术平台。我的旅程从支持企业基础设施开始，到现在领导负责在非洲各地交付关键任务的平台工程、DevSecOps 和基础设施团队。

    每一个角色都拓展了我的技术专长、领导责任以及将工程与业务成果相结合的能力。如今，我的重点是构建加速软件交付的平台，同时将安全性、可观测性、自动化和可靠性融入技术栈的每一层。

    信息技术副经理¶

    Eclectics International·2021年4月 – 至今

    作为信息技术副经理，我领导负责企业基础设施、平台工程、DevSecOps、云转型和卓越运营的工程团队。在与多个业务部门合作时，我帮助制定技术战略，同时确保支撑关键金融和企业系统的平台保持安全、高可用且有弹性。

    工程领导¶

    • 领导负责企业技术平台的平台工程、基础设施和系统工程团队。
    • 制定基础设施标准、治理、运营流程和长期技术路线图。
    • 指导工程师，并推动以自动化、可靠性、持续改进和知识共享为核心的文化。
    • 与业务和技术利益相关者合作，交付符合组织目标的战略基础设施计划。

    平台工程¶

    • 设计并运营支持现代云原生应用的高可用 Kubernetes 平台。
    • 架构优先考虑可扩展性、弹性、安全和运营简洁性的混合云环境。
    • 通过基础设施即代码、GitOps 和自动化部署实践标准化平台能力。
    • 构建可复用的工程平台，在降低运营复杂性的同时提升开发者生产力。

    DevSecOps 与自动化¶

    • 在所有 CI/CD 流水线中实施安全、合规和质量实践。
    • 鼓励基础设施流程自动化，避免重复工作并确保部署的一致性。
    • 支持采用将安全融入软件部署的 DevSecOps 实践，同时不拖慢开发进程。

    可观测性与可靠性¶

    • 使用 Prometheus、Grafana、Loki、OpenTelemetry 等工具及其他云原生技术开发集中式可观测性系统。
    • 通过监控、告警、日志记录和分布式追踪提升运营中的可观测性能力。
    • 通过实施可靠性工程、主动事件管理和性能优化的最佳实践，实现系统的健壮性。

    安全与业务连续性¶

    • 在 PCI-DSS 架构中承担基础设施项目的安全责任。
    • 实施企业安全控制、基础设施加固、漏洞管理和治理。
    • 制定灾难恢复和业务连续性计划。

    职业亮点¶

    • 通过云原生平台工程实现企业基础设施现代化。
    • 在工程团队中标准化 CI/CD 和基础设施即代码实践。
    • 构建了企业可观测性能力，提升了运营感知并加速了事件响应。
    • 通过高可用 Kubernetes 架构和自动化运营增强了平台弹性。
    • 在保持交付速度的同时，将安全和合规嵌入工程工作流。

    技术：KubernetesDockerHelmCiliumGitLab CI/CDJenkinsTerraformAnsiblePrometheusGrafanaLokiOpenTelemetryLinuxWindows ServerMicrosoft Hyper-VAWSAzureGitOps

    高级系统管理员¶

    Eclectics International·2019年1月 – 2021年3月

    晋升为领导企业系统管理和基础设施现代化计划，将传统基础设施与新兴云原生技术连接起来。

    在此期间，我专注于提升平台稳定性、加强安全性、扩展自动化，并为组织向现代平台工程实践转型奠定基础。

    主要贡献¶

    • 管理支持生产负载的企业 Linux 和 Windows 基础设施。
    • 引入集中式监控、告警和运营仪表板，提升了平台可见性。
    • 在企业环境中实施 CIS 加固标准和 PCI-DSS 安全控制。
    • 自动化常规基础设施运营，减少人工投入并提高一致性。
    • 与软件工程团队紧密合作，改进部署流程和平台可靠性。
    • 通过主动维护、性能调优和运营最佳实践提升系统可用性。

    技术：LinuxWindows ServerVMwareMicrosoft Hyper-VGrafanaNagiosIcingaBashPowerShellNetworkingSecurity Hardening

    系统管理员¶

    Eclectics International·2017年10月 – 2018年12月

    负责支持企业基础设施、虚拟化、网络和日常运营，同时发展系统工程、自动化和信息安全方面的专长。

    这个角色奠定了后来发展为平台工程和基础设施领导力的技术基础。

    主要贡献¶

    • 管理支持企业运营的 Linux 和 Windows 服务器基础设施。
    • 管理虚拟化平台、企业网络、DNS、DHCP、防火墙和系统管理。
    • 通过基础设施加固和安全改进支持 PCI-DSS 合规计划。
    • 为监控、文档、事件响应和运营流程改进做出贡献。
    • 开始引入自动化实践，提升了运营效率和服务可靠性。

    技术：LinuxWindows ServerVMwareMicrosoft Hyper-VNetworkingDNSDHCPpfSenseBashMonitoring

    IT 技术员¶

    肯尼亚海洋与渔业研究所（KMFRI）·2015年6月 – 2017年9月

    从终端用户支持和企业 IT 运营的工作中，我获得了在硬件、网络、故障排除和客户支持方面的丰富经验。

    我从与研究人员和管理人员的合作中认识到，技术不仅关乎系统本身，更关乎让人们发挥出最佳水平。这一理念至今仍影响着我对平台工程的理解。

    主要贡献¶

    • 台式机、笔记本电脑、打印机和外设的安装、配置与维护。
    • 硬件、软件、操作系统和网络连接的支持。
    • 协助结构化布线、工作站部署和基础设施维护。
    • 管理 IT 资产与运营。
