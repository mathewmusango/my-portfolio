# 专业经验

在过去十年中，我围绕一个目标构建了自己的职业生涯：创建安全、可扩展、有弹性且易于工程团队使用的技术平台。我的旅程从支持企业基础设施开始，到现在领导负责在非洲各地交付关键任务的平台工程、DevSecOps 和基础设施团队。

每一个角色都拓展了我的技术专长、领导责任以及将工程与业务成果相结合的能力。如今，我的重点是构建加速软件交付的平台，同时将安全性、可观测性、自动化和可靠性融入技术栈的每一层。

## 信息技术副经理

<p class="exp-meta"><span class="exp-company">Eclectics International</span><span class="exp-meta-sep">·</span><span class="exp-dates">2021年4月 – 至今</span></p>

作为信息技术副经理，我领导负责企业基础设施、平台工程、DevSecOps、云转型和卓越运营的工程团队。在与多个业务部门合作时，我帮助制定技术战略，同时确保支撑关键金融和企业系统的平台保持安全、高可用且有弹性。

### 工程领导

- 领导负责企业技术平台的平台工程、基础设施和系统工程团队。
- 制定基础设施标准、治理、运营流程和长期技术路线图。
- 指导工程师，并推动以自动化、可靠性、持续改进和知识共享为核心的文化。
- 与业务和技术利益相关者合作，交付符合组织目标的战略基础设施计划。

### 平台工程

- 设计并运营支持现代云原生应用的高可用 Kubernetes 平台。
- 架构优先考虑可扩展性、弹性、安全和运营简洁性的混合云环境。
- 通过基础设施即代码、GitOps 和自动化部署实践标准化平台能力。
- 构建可复用的工程平台，在降低运营复杂性的同时提升开发者生产力。

### DevSecOps 与自动化

- 在所有 CI/CD 流水线中实施安全、合规和质量实践。
- 鼓励基础设施流程自动化，避免重复工作并确保部署的一致性。
- 支持采用将安全融入软件部署的 DevSecOps 实践，同时不拖慢开发进程。

### 可观测性与可靠性

- 使用 Prometheus、Grafana、Loki、OpenTelemetry 等工具及其他云原生技术开发集中式可观测性系统。
- 通过监控、告警、日志记录和分布式追踪提升运营中的可观测性能力。
- 通过实施可靠性工程、主动事件管理和性能优化的最佳实践，实现系统的健壮性。

### 安全与业务连续性

- 在 PCI-DSS 架构中承担基础设施项目的安全责任。
- 实施企业安全控制、基础设施加固、漏洞管理和治理。
- 制定灾难恢复和业务连续性计划。

#### 职业亮点

<div class="exp-hl" markdown>

- 通过云原生平台工程实现企业基础设施现代化。
- 在工程团队中标准化 CI/CD 和基础设施即代码实践。
- 构建了企业可观测性能力，提升了运营感知并加速了事件响应。
- 通过高可用 Kubernetes 架构和自动化运营增强了平台弹性。
- 在保持交付速度的同时，将安全和合规嵌入工程工作流。
