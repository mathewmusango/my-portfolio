# 站点图谱

本网站以小型、版本驱动的方式迭代。每个版本都会被标记并发布，附带其源代码归档和软件物料清单（SBOM），完整的按版本说明见[更新日志](https://github.com/mathewmusango/my-portfolio/blob/main/CHANGELOG.md)。

!!! note
    每个版本都附带源码归档和根据固定依赖生成的 CycloneDX SBOM。

## 仓库 {#the-repository}

本站以开放方式开发，从公开仓库
[`mathewmusango/my-portfolio`](https://github.com/mathewmusango/my-portfolio){ target="_blank" rel="noopener" } 发布。
