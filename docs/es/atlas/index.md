# Atlas del Sitio

Este sitio evoluciona en pasos pequeños impulsados por versiones. Cada versión
está etiquetada y publicada con su archivo fuente y su lista de materiales de
software (SBOM), y las notas completas por versión viven en el
[CHANGELOG](https://github.com/mathewmusango/my-portfolio/blob/main/CHANGELOG.md).

!!! note
    Cada release incluye un archivo fuente y un SBOM CycloneDX generado a partir de las dependencias fijadas.

## El Repositorio {#the-repository}

El sitio se desarrolla en abierto y se publica desde el repositorio público
[`mathewmusango/my-portfolio`](https://github.com/mathewmusango/my-portfolio){ target="_blank" rel="noopener" }.
